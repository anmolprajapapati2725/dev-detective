# Dev Detective 🔍

A GitHub Profile Search Application built using HTML, CSS and JavaScript.

## Features

* Search GitHub users by username
* Fetch data using GitHub REST API
* Display user profile information

  * Avatar
  * Name
  * Bio
  * Join Date
  * Portfolio URL
* Loading State while fetching data
* Error Handling for invalid usernames
* Display Top 5 Latest Repositories
* Repository links open in a new tab
* Human-readable date formatting
* Battle Mode using Promise.all()
* Compare total repository stars between two users
* Display Winner and Loser based on star count

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6+)
* Fetch API
* Async/Await
* GitHub REST API

2. Open the project folder.
